# Card Icon Set

Store `Card Collection` icons in this folder.

Naming convention:

- `icon-card-{slug}.svg`
- Use lowercase kebab-case slugs.
- ASCII letters, numbers, and hyphens only.
- Examples: `icon-card-check-in.svg`, `icon-card-room-service.svg`, `icon-card-digital-key.svg`.

In ACF, select the matching slug in the `Icon Name` dropdown.
